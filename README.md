# fourfourbeat-web

포포 비트(FourFour Beat) 소개 사이트 — https://fourfourbeat.taegabi.com

- `index.html` 소개 · `privacy.html` 개인정보처리방침 · `terms.html` 이용약관 · `delete.html` 계정·데이터 삭제 안내 (한국어). `en/`, `ja/`에 같은 페이지의 영어·일본어판
- 화면 이미지 `assets/screens/<ko|en|ja>/`: 앱의 `tests/store_shots.tscn` 원본에서 위아래 광고 띠를 잘라 낸 것
- GitHub Pages(main 브랜치 루트)로 배포, 도메인은 `CNAME`
- 광고(AdMob)를 붙이면 개인정보처리방침에 광고 항목을 추가하고 `app-ads.txt`를 올릴 것
