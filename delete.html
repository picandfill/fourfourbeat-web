계정과 데이터 삭제

포포 비트(개발자: Taegabi Studio)는 로그인 없이 익명 계정으로 순위표에 참여합니다. 아래 방법으로 서버의 순위 기록과 익명 계정을 지울 수 있습니다.

앱에서 바로 지우기

  1. 포포 비트를 열고 메인 메뉴에서 설정을 누릅니다.
  2. 데이터 삭제를 누릅니다.
  3. 확인 창에서 삭제를 누릅니다.

서버의 순위 기록(닉네임·나라·점수 등)과 익명 계정이 바로 지워지고, 휴대폰에 저장된 기록·배지·설정·음표·꾸밈 아이템도 함께 지워집니다. 인터넷이 끊겨 있으면 다음에 앱을 켤 때 서버에서 지웁니다.

앱을 이미 지웠다면

contact@taegabi.com으로 "기록 삭제 요청"이라고 보내 주세요. 로그인이 없어 계정을 이메일로 찾을 수 없으므로, 순위표에 쓰던 닉네임, 나라, 대략의 최고 점수를 함께 적어 주세요.

7일 안에 해당 기록과 익명 계정을 지우고 답장으로 알려 드립니다.

지워지는 것과 남는 것

  • 지워짐: 익명 사용자 식별자, 모든 모드의 기록과 종합 점수(닉네임, 나라, 최고 점수, 클리어 수, PERFECT·GOOD·MISS 수, 기록 시각)
  • 남는 것 없음: 운영자는 삭제한 기록을 따로 보관하지 않습니다. 삭제 요청 메일만 답변 후 1년 안에 지웁니다.
